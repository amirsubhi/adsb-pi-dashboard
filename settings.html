How to change a setting

  1. On the Pi, open the settings file and edit the line for the option. Remove the # at the start of the line to use it.
    nano ~/adsb-dashboard/settings.ini
  2. Restart the dashboard to apply it.
    sudo systemctl restart adsb-dashboard
  3. Reload this page and check the value and where it comes from.

A setting marked environment comes from the service file and overrides settings.ini. Remove that Environment= line from /etc/systemd/system/adsb-dashboard.service if you'd rather manage it in settings.ini.
